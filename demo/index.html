🛡 Fault Tolerance — Chọn Kịch Bản Kiểm Tra
● IDLE
📨
Kafka Broker Crash
Kill Kafka container, insert data during outage, restart, verify zero data loss. Demonstrates message durability và Debezium offset persistence.
~45s Auto-recover ✓
Hypothesis: Debezium buffers binlog offset. Khi Kafka restart, Debezium replay từ vị trí đã lưu → 0 message lost.
🔗
Debezium Connector Restart
Restart Debezium container, insert records during downtime, verify offset preserved — Debezium catches up from MySQL binlog position.
~30s Auto-recover ✓
Hypothesis: MySQL binlog lưu mọi change. Debezium lưu offset trong Kafka. Restart → tiếp tục từ offset → không bỏ qua event nào.
⚙
Spark Driver Crash
Kill Spark streaming job mid-stream. Re-submit với checkpoint hiện có. Verify MongoDB không có duplicate và không mất data.
~90s Checkpoint ✓
Hypothesis: Spark checkpoint lưu Kafka offset của batch đã hoàn thành. Restart → reprocess batch chưa commit → MongoDB upsert idempotent → no duplicate.
